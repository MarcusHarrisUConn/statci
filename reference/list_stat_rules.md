# List available statistical lint rules

Returns a tibble summarizing all currently registered statistical lint
rules (built-in plus any user-registered custom rules).

## Usage

``` r
list_stat_rules(category = NULL, severity = NULL)
```

## Arguments

- category:

  Optional character vector to filter rules by category.

- severity:

  Optional character vector to filter rules by severity (`"error"`,
  `"warning"`, `"info"`).

## Value

A [tibble::tibble](https://tibble.tidyverse.org/reference/tibble.html)
with columns `id`, `severity`, `category`, `title`, `description`, and
`recommendation`.
